# Eye tracking and voice v1.0.4 — first experimental marketplace package

Plugin 1.0.4 with unchanged native helper 1.0.3. Project license: Apache-2.0; third-party notices included.

Download **workswarm-eye-voice-1.0.4-marketplace.zip** and import it into WorkSwarm. First Start automatically acquires the pinned helper; a manual helper download is unnecessary. See [setup instructions](https://github.com/aliparchekan/workswarm-eye-voice-releases/blob/main/SETUP.md).

- Local 14-dot calibration, session-based gaze and wake-first voice input.
- Requests and live replies in the confirmed WorkSwarm chat.
- Draft/attachment protection and verified companion download/cache.
- Package: 840,380 bytes. Helper archive: 168,446,993 bytes.
- Official publisher/import checks passed; 801 Python and 78 JavaScript tests passed.

**Experimental, Apple-silicon macOS only.** Tested host: WorkSwarm 0.2.8, English Safari/Chrome. Vision-capable model required. Helper is ad-hoc signed, not notarized; fresh-Mac physical acceptance remains unverified. No new model is bundled.

This is a GitHub distribution release, not marketplace approval. Marketplace submission is blocked by Agentic Hub’s unavailable sign-in provider. Checksums are supplied in SHA256SUMS. Private source history and personal demo data are not published.
