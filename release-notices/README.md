# Third-party notices

These files accompany the native helper and marketplace plugin. Each component retains its own license; the plugin's selected license does not replace these terms.

`inventory.json` records the component/version and SHA-256 of each supplied notice. Python distribution notices were collected from the build environment for modules included in PyInstaller's analysis. Pillow's 70 KB license file includes its bundled image/font/compression libraries. PyInstaller's COPYING includes its bootloader exception. Electron/Chromium notices are also retained inside the signed app. Pinned WorkSwarm and composer notices are copied from the actual build sources. MediaPipe's Apache-2.0 text is retained with its pinned assets.

This inventory records upstream-supplied notices; it is not a legal opinion or a guarantee about every transitive dependency. Original copyright notices in source and runtime files remain intact.
